# Cómo contactar a los proveedores de IA (Perfect Corp / Banuba)

Plantillas listas para copiar y adaptar. Rellena los huecos [entre
corchetes] con tus datos antes de enviar.

## Email (sirve para ambos, cambia solo el nombre de la empresa)

**Asunto:** Evaluación de API de previsualización de corte de pelo — piloto HairVision

Hola,

Soy [tu nombre], fundador/a de HairVision, una aplicación para tablet
pensada para peluquerías: ayuda a la estilista a mostrar a la clienta una
previsualización aproximada de un corte antes de realizarlo.

Estamos terminando un MVP y preparando un piloto con 3-5 peluquerías
durante 2-3 meses, con un volumen estimado de unas 20-30
previsualizaciones por semana por peluquería. Nos gustaría evaluar
[Perfect Corp / Banuba] como proveedor de la parte de previsualización de
corte sobre foto.

Querríamos, si es posible:

1. Acceso a una clave de prueba (trial/API key) para evaluar la calidad
   del resultado con fotos reales nuestras.
2. Una cotización orientativa para el volumen del piloto descrito arriba,
   y cómo escala el precio si crecemos a más peluquerías.
3. Confirmar si el procesamiento de la foto ocurre en la nube o en el
   propio dispositivo — es un punto importante para nosotros por la
   privacidad de nuestras clientas.

Quedo atento/a, gracias de antemano.

[Tu nombre]
HairVision
[tu email / teléfono]

## Si prefieres llamar: guion corto

Úsalo como chuleta, no hace falta leerlo literal.

1. "Hola, soy [nombre], estoy montando una app para peluquerías llamada
   HairVision y quiero evaluar vuestra API de previsualización de corte
   de pelo para un piloto pequeño."
2. "¿Tenéis una clave de prueba gratuita para probar la calidad con
   fotos reales?"
3. "Para un piloto de 3-5 peluquerías, unas 20-30 previsualizaciones por
   semana cada una, ¿me podéis dar una cotización orientativa?"
4. "Una pregunta importante para nosotros: ¿la foto se procesa en vuestra
   nube o en el propio dispositivo del cliente?" (Apunta la respuesta —
   es la pregunta que más nos importa comparar entre proveedores.)
5. "¿Cuál es el siguiente paso para conseguir acceso de prueba?"

## Dónde encontrar el contacto de cada uno

- **Perfect Corp / YouCam API:** portal de desarrolladores en
  `yce.perfectcorp.com` — clave de prueba gratuita autoservicio, sin
  necesidad de llamar primero.
- **Banuba:** formulario de contacto en `banuba.com` — normalmente piden
  rellenar un formulario y te contactan ellos para la cotización.

## Qué hacer con la respuesta

Cuando tengas respuesta de alguno (o de los dos), pásamela — la comparamos
contra `docs/proveedores-ia.md` y decidimos juntos antes de tocar ni una
línea de código.
