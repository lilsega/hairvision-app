# Documentación de producto

Esta carpeta guarda documentación que no es código: visión de producto,
decisiones tomadas y (más adelante) investigación de usuario, roadmap, etc.

- `guia-para-sega.md` — empieza por aquí si algo de la carpeta no se
  entiende. Explica cada parte del proyecto en lenguaje sencillo.
- `plan-proximos-meses.md` — el plan REAL a seguir ahora mismo (3 meses,
  con dinero real y pasos concretos). Empieza por aquí para saber qué
  hacer esta semana.
- `guion-presentacion-peluquerias.md` — qué llevar, qué decir y qué
  preguntar al presentar HairVision en persona a una peluquería.
- `manual-uso-peluqueria.md` — para entregar junto a la tablet: cómo
  usarla día a día, qué decir a las clientas, y qué hacer si algo falla.
- `ideas-y-tareas-pendientes.md` — todo lo pendiente y las ideas nuevas,
  ordenado por complejidad/prioridad. Empieza aquí al retomar el proyecto.
- `plan-de-negocio.md` — el plan de negocio "de presentación" (para
  inversores/socios más adelante), documento vivo.
- `proveedores-ia.md` — comparativa de proveedores de IA para la previsualización de cortes
